# Tutorials

Tutorials explain OMTX workflows step by step and show how the pieces fit
together.

Use this section when you want to learn a workflow, not just copy a final
recipe.

## Tutorials

- [Data Access Python Workflows](data-access-python-workflows.md): load paired
  binder/non-binder pools, explicit pools, raw shard URLs, and molecule previews.
- [Diligence Jobs](diligence-jobs.md): submit diligence jobs, poll status, handle
  terminal states, and use retry-safe idempotency keys.
- [Historical Hub Jobs And Artifacts](hub-jobs-and-artifacts.md): inspect existing
  jobs and request authorized result URLs. New execution uses
  [ZenCloud](../skills/om-discovery/SKILL.md#case-19--zencloud-scientific-sessions).

## Best Practices

- Teach one workflow at a time.
- Use production endpoints and current SDK methods.
- Use example inputs or data you have permission to access.
- Keep the focus on customer workflows and results.
